# RuVoice — отдельный конвейер улучшения ударений

Эта папка изолирована от Android-проекта. Здесь хранятся генератор пользовательского словаря, тесты, промежуточные отчёты и готовые TXT для импорта. Скрипты **не меняют APK, Gradle, исходники приложения или системный словарь Stage 4.9**.

## Что уже сохранено

- **build_dictionary.py** — объединяет проверенные списки и кандидатов, проверяет формат RuVoice и не разрешает спорным вариантам попасть в автоматический словарь.
- **test_build_dictionary.py** — тесты формата, е/ё, конфликтов источников, порога повторений и отложенных кандидатов.
- **run_pipeline.sh** — запускает словарный проход в одноразовой временной копии официального RuVoice. Временная копия удаляется при завершении; оригинальные файлы твоего репозитория не перезаписываются. Он читает сжатый Wiktextract JSONL потоково — без распаковки 2,3 ГБ на диск.
- **analyze_book.py** — проверяет EPUB/TXT/HTML по словарю и создаёт контексты для слов, которые уже есть в словаре и которых не хватает.
- **output/** — готовые словари для импорта, включая отдельный проверенный override для конфликта «Трёхгорка».
- **data/curated/reviewed_overrides.txt** — вручную подтверждённые точечные переопределения с источниками; этот файл подключается к полному конвейеру до автоматических кандидатов.
- **reports/** — причины отклонения, конфликты и версии источников.
- **reports/RuVoice_AutoStress_accepted.tsv** — аудит источника каждой строки собранного словаря (Stage 4.9, ручной override или AOT + Wiktionary consensus).
- **.cache/** и **data/raw/** — локальные большие зависимости и словарные дампы; они исключены из Git.

## Быстрый локальный тест

Из корня репозитория:

~~~bash
python3 -m unittest discover -s experiments/ruvoice-stress-dictionary -v
~~~

## Пересобрать базовый словарь из Stage 4.9

Этот файл собирается из уже существующего файла:

project/ruvoice-1.1.3-stage4.9/tools/stress_fixes.txt

Это **снимок текущих поправок Stage 4.9**, а не заявление, что каждая запись новая по сравнению с установленной версией приложения.

~~~bash
python3 experiments/ruvoice-stress-dictionary/build_dictionary.py \
  --source-list project/ruvoice-1.1.3-stage4.9/tools/stress_fixes.txt \
  --output experiments/ruvoice-stress-dictionary/output/RuVoice_Stage4.9_ExistingFixes.txt \
  --report experiments/ruvoice-stress-dictionary/reports/Stage4.9_ExistingFixes_review.tsv \
  --manifest experiments/ruvoice-stress-dictionary/reports/Stage4.9_ExistingFixes_manifest.json
~~~

## Полный автоматический проход

Полный запуск настроен через GitHub Actions workflow **Build automatic RuVoice stress dictionary**. Он запускается добавлением файла `RUN_FULL_PIPELINE.md` (текущий триггер) или вручную из Actions → Build automatic RuVoice stress dictionary → Run workflow. После успешного запуска TXT, TSV-отчёт и манифест будут автоматически сохранены отдельным коммитом в эту ветку.

Нужны Linux/macOS или WSL, git, curl, Python 3 и свободное место под виртуальное окружение и словарные данные. Первый запуск устанавливает silero-stress, получает AOT, а также скачивает сжатый raw Wiktextract JSONL русскоязычного Wiktionary (около 272,5 МБ, распакованный объём 2,3 ГБ по снимку 2026-11-01). Исходные корпуса не добавляются в Git.

Положи файл raw-wiktextract-data.jsonl.gz сюда:

~~~text
experiments/ruvoice-stress-dictionary/data/raw/
~~~

Либо разреши скрипту скачать его:

~~~bash
cd experiments/ruvoice-stress-dictionary
DOWNLOAD_WIKT=1 bash run_pipeline.sh
~~~

Если файл уже лежит в другом месте:

~~~bash
WIKT_GZ=/путь/к/raw-wiktextract-data.jsonl.gz bash run_pipeline.sh
~~~

Скрипт выполняет следующий проход:

1. Клонирует официальный kost-t-human/ruvoice-tts во временный каталог.
2. Берёт морфологические формы AOT и формы с ударениями из Kaikki/Wiktionary.
3. Прогоняет однозначные формы через silero-stress.
   Полный русский AOT источник берётся строго из `morph_dict/data/Russian/morphs.json` и `gramtab.json`; после генерации включён минимальный порог 100 000 строк, чтобы маленькие тестовые JSON из других каталогов случайно не стали основой словаря.
4. Оставляет расхождения модели только там, где AOT и Викисловарь согласны по ударению.
5. Добавляет существующий список Stage 4.9 первым, с наивысшим приоритетом; новые автоматические записи не могут его переопределить.
6. Создаёт TXT для импорта, TSV со спорными строками и JSON-манифест с версией официального исходника.

Официальный stress_fixes.py build перезаписывает свой tools/stress_fixes.txt. Поэтому он запускается **только во временном клоне** официального проекта, который удаляется после выполнения. Файлы Stage 4.9 в этом репозитории остаются нетронутыми.

## Полное сравнение двух производственных цепочек

Для книги `8.Iskusstvo..epub` выполнено сравнение исходной цепочки RuVoice с вариантом, дополненным производственным RUAccent ONNX и текущей защищённой грамматико-BERT-логикой:

- `reports/8-Iskusstvo-paired-comparison.md` — агрегированные показатели, пять ручных stress-regression checks, 29 проверок «ё» и ограничения интерпретации.
- `reports/8-Iskusstvo-stress-movements-review.tsv` — 71 уникальная пара изменённого ударения с количеством вхождений; все строки помечены `UNREVIEWED_NOT_GOLD`.
- `reports/8-Iskusstvo-auto-dictionary-scan.json` — сравнение покрытия книги базовыми 1 924 и итоговыми 4 587 записями; только агрегаты, без цитат книги.
- `reports/RuVoice_AutoStress_system-conflict-audit.md` — проверка всех 2 661 новых автоматических форм на конфликты с полным встроенным `Системный.txt`.

Парное сравнение прошло на 65 109 токенах без лексических или выравнивающих ошибок. Новый список увеличил точное словарное покрытие книги с 288 до 295 вхождений (с 23 до 28 словоформ), то есть с 0,46% до 0,47%. Пять новых словоформ дали семь вхождений. Это словарное покрытие, а не метрика правильности ударений; EPUB не имеет полной эталонной разметки. Все 2 661 автоматические записи проверены на пересечение со встроенным системным словарём: девять уже присутствуют с тем же ударением, конфликтов по точному ключу или нормализации е/ё не найдено.

## Импорт словаря

В RuVoice открой вкладку словарей → **«Ударения»** → импорт TXT. Импортируй файл в отдельный список, например **«Автоударения»**, и включи его. Не импортируй во вкладку «Замены».

Пользовательские списки в официальном RuVoice имеют приоритет над системным списком. Если текущая установленная версия приложения уже содержит те же записи, повторный импорт не даст дополнительного эффекта; этот экспорт полезен для отдельного пользовательского списка и переноса поправок на другую установку.

## Проверенные точечные переопределения

В `data/curated/reviewed_overrides.txt` лежат две формы имени собственного «Трёхгорка»: `трёхгорке трёхг+орке` и `трёхгорку трёхг+орку`. Они разрешают две конфликтующие записи в системном словаре: `тр+ёхгорке` и `трёхг+орке`. Орфографический словарь указывает основное ударение на «о» (Трёхгóрка); «ё» в сложном слове может обозначать побочное ударение. Источники и номера строк исходного системного списка сохранены в `reports/Trekhgorka-conflict-audit.json`.

Это отдельный общий override, не ошибка, обнаруженная в загруженной книге. Он импортируется в свой список, поэтому исходный встроенный словарь не переписывается.

## Политика безопасности отбора

- Запись должна быть одним русским словом и иметь ровно один плюс непосредственно перед гласной.
- Ключ и форма должны совпадать (разрешено различие е/ё).
- Односложные слова не добавляются.
- Более ранний источник имеет приоритет. Конфликтующие записи попадают в отчёт, а не выбираются наугад.
- Для stress_candidates.txt требуется не менее трёх контекстов. Это фильтр повторяемости, **не вероятность правильного ударения**.
- stress_fixes_new.txt из официального build3 остаётся только в отчёте: сам официальный скрипт помечает его как «на просмотр».
- В словарь не добавляются автоматически неоднозначные омографы, имена и записи, для которых нет согласия источников.

Никакая статистика повторений не гарантирует стопроцентную точность. Перед широким использованием проверяй спорные слова на контексте, особенно омографы, имена, термины и редкие формы.

## Проверка своей книги

В репозитории уже есть книга `private-files/8.Iskusstvo..epub` (826 КБ). Повторно загружать её не нужно: CI автоматически проверяет её и против списка поправок Stage 4.9, и против полного встроенного системного словаря. Сводка последнего успешного прогона находится в `reports/8-Iskusstvo-stage49-scan.md`. CI отдельно подтверждает сборку проверенных ручных overrides.

Другие EPUB/TXT/HTML-книги можно проверить локально, не добавляя их в Git. Сканер поддерживает EPUB, TXT и HTML; выводит взвешенное покрытие словарём, встречаемость известных слов с контекстами, а также частотный список не покрытых словоформ с примерами.

~~~bash
python experiments/ruvoice-stress-dictionary/analyze_book.py /путь/к/книге.epub \
  --dictionary experiments/ruvoice-stress-dictionary/output/RuVoice_AutoStress.txt \
  --output-dir experiments/ruvoice-stress-dictionary/reports/book_scans/my_book
~~~

Результаты анализа книги (там могут быть фрагменты авторского текста) локальные и исключены из Git через .gitignore. Само покрытие не является метрикой правильности ударений: оно показывает только, какие точные словоформы найдены в словаре.

Отсутствующая словоформа не доказывает ошибку акцентатора: обычные слова остаются за моделью, а омографы часто разрешаются правилами-фразами на вкладке «Замены». Сам текст книги не считается источником «истинного» ударения автоматически — правильность подтверждается словарями или независимыми источниками.

Парная оценка RuAccent относительно исходного RuVoice запускается и в публичной ветке по решению владельца. Отчёт сохраняет отдельные слова и агрегированные показатели, но не публикует длинные книжные контексты.

## Источники и лицензии

- [Официальный RuVoice](https://github.com/kost-t-human/ruvoice-tts) — скрипты сравнения, сборки поправок и форматы словарей.
- [AOT / morph_dict](https://github.com/sokirko74/morph_dict) — морфологические данные на основе грамматического словаря Зализняка.
- [Kaikki: Russian dictionary](https://kaikki.org/dictionary/Russian/index.html) — словарные формы, извлечённые из англоязычного Wiktionary; страница указывает источник и дату дампа.
- [Kaikki raw-data downloads](https://kaikki.org/ruwiktionary/rawdata.html) — обновляемые выгрузки Wiktextract. Wiktionary/Kaikki требует соблюдения применимых CC BY-SA/GFDL условий; исходный дамп не хранится в этом репозитории.
- silero-stress — библиотека сравнения, которую вызывает официальный скрипт.

## Состояние на 2026-11-24

Полный AOT + Wiktionary проход успешно выполнен (GitHub Actions run `45464373427`). Итоговый `output/RuVoice_AutoStress.txt` содержит 4 587 уникальных корректно размеченных записей:
- 1 924 исходные записи Stage 4.9, сохранённые без изменений;
- 2 661 автоматическую поправку, выбранную официальным `stress_fixes.py build` при расхождении Silero с согласующимися AOT и Wiktionary;
- 2 проверенные вручную curated overrides.

Полный русский AOT дал 2 126 307 словоформ; из них 1 986 688 однозначных форм проверены Silero, обнаружено 29 444 расхождения (1,48%), из которых upstream собрал 3 284 кандидата. После фильтров и приоритетов источников в итоговый TXT вошли 2 661 новая автоматическая запись. Наличие трёх отклонённых/отложенных строк отражено в `reports/RuVoice_AutoStress_review.tsv`.

`reports/RuVoice_AutoStress_accepted.tsv` показывает источник каждой строки итогового TXT. Автоматическая строка не означает ручную или корпусную gold-проверку; частота и согласие двух словарных источников не являются калиброванной вероятностью.

Сканер `8-Iskusstvo` против нового TXT выполнен workflow `Scan generated RuVoice dictionary against book`; его отчёт сохраняет только агрегаты и не публикует контексты книги. Android-проект и APK не менялись.

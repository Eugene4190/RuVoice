## Цель проекта

Основная задача — контекстная проверка произношения всей книги исходным production RuVoice и выдача только тех пользовательских поправок, которые подтверждены достаточными свидетельствами. EPUB не изменяется; е/ё не переписываются; глобальные системные словари и APK-assets не редактируются.

## Изменения этого прохода

1. Исправлен Windows CP1252 crash при загрузке `ruaccent-predictor`: отдельный UTF-8 bootstrap настраивает stdin/stdout/stderr до импорта модели. Причина была воспроизведена в логе предыдущего Windows CI: вывод символа 📖 завершался `UnicodeEncodeError`.
2. PyInstaller получает обе директории поиска модулей, включая папку с UTF-8 bootstrap.
3. Родительский сервер явно декодирует stdout/stderr portable worker как UTF-8; системная кодировка Windows больше не используется для этого протокола.
4. Полный режим третьей модели теперь fail-closed: он не может завершиться успешно, если хотя бы одно ожидаемое многосложное русское словоупотребление не выровнено с предсказанием модели или появились неожиданные координаты.
5. Контекстный отчёт больше не подставляет результат RuVoice вместо отсутствующего вывода RUAccent. Невыровненные случаи остаются явно без независимого свидетельства. Координаты полного книжного оверлея проверяются точным сравнением множеств, а не только количеством строк.

## Что не даёт объявить проект готовым

- Репозиторий публичный. CI определяет `RUVOICE_REFERENCE_BOOK_PRIVATE=false` и поэтому не обрабатывает личный reference EPUB; запускается только синтетическая книга. Не помещать личную книгу или её текст в публичные коммиты, логи и артефакты.
- Следовательно, текущие проверки не доказывают полный прогон именно целевой книги оригинальным production RuVoice, сборку её ZIP и повторный полный прогон после импорта исправлений.
- 100% ledger coverage означает, что каждому токену соответствует запись, а не что каждому слову доказано нормативное контекстное ударение.
- Служебные слова, односложные формы, OOV и случаи без достаточных независимых источников остаются в явных категориях для контекстной/ручной проверки. Третий predictor — дополнительное свидетельство, не эталон.
- Перед статусом «готово» необходимо на защищённом приватном окружении прогнать целевой EPUB, разобрать оставшиеся спорные контексты, проверить штатные форматы списков RuVoice, импортировать пакет и повторно прогнать ту же книгу без регрессий.

## Границы

- `main` не изменять; PR #1 не сливать без отдельного решения пользователя.
- Не менять исходный EPUB, встроенный системный словарь, APK-assets и движок без отдельной необходимости.

# Текущий статус личного workflow RuVoice

Дата: 2026-11-25. Рабочая ветка: `stress-dictionary-pipeline`.

## Что уже реализовано

- Локальная страница загрузки `private_book_server.py`: доступ только через `127.0.0.1`, EPUB до 256 МБ, необязательный TXT с книжными replacements. Есть token/Origin/Host checks; HTTP-логи не сохраняют имена и текст книг.
- Входная EPUB и replacement-TXT пишутся во временную папку с приватными правами; после обработки оба временных файла удаляются **до** отправки ссылки на ZIP.
- Запуск: Windows — двойной щелчок по `Start_RuVoice_Book_Tool_Windows.bat`; macOS/Linux — `bash start_ruvoice_book_tool.sh`. Требуется Python 3.11+. Страница открывается на `http://127.0.0.1:8765/`.
- Приватный накопитель вне Git по умолчанию `~/.ruvoice-book-workflow` (Windows: `%USERPROFILE%\\.ruvoice-book-workflow`). Каталоги имеют права 0700, файлы — 0600 на POSIX. Хранение локальное, не облако и не шифрованное хранилище.
- `personal_book_workflow.py` автоматически добавляет в append-only мастер только кандидатов разрешённых источников после exact spelling/е-ё, context-rule и master-conflict checks. Используется staged-копия и конфликтный валидатор; старое утверждённое ударение не перезаписывается.
- SHA-256 EPUB обеспечивает идемпотентность: повторная обработка той же книги не добавляет дубликатов и выдаёт пустую дельту.
- Приватная история хранит книгу добавления, источник и частоту записи, а также все книги, в которых утверждённая форма встретилась позднее. Текст EPUB в историю/ZIP не включается.
- ZIP выдаёт имена списков с названием книги: `<Book>_New_Stress_Delta.txt` и `<Book>_Replacements.txt`. Также внутри есть `MyBooks_Cumulative.txt`, `MyBooks_History.json`, `IMPORT.txt`, `Book_Report.json`, review/conflict и unresolved TSV.
- Книжные replacements хранятся отдельно по SHA-256 книги. Пользовательский TXT можно приложить при загрузке; уже сохранённые правила не пропадают при повторе EPUB.
- Добавлен первый безопасный auto-selection контекстной замены: вручную проверенные phrase rules из `private-files/paired_eval/book_reviewed_replacements.txt` попадают в ZIP только если буквальная фраза обнаружена в конкретной книге. Сейчас это небольшой curated набор (в нём пока одно правило «шелка и»), а не универсальное автоматическое извлечение фраз из прозы.

## Что ещё нужно для полной приёмки

1. Запустить локальную страницу и пройти настоящий пользовательский EPUB через браузер, проверить ZIP и приватную папку.
2. Расширить curated phrase rules и/или разработать безопасный механизм предложения новых контекстных replacements из конкретной книги; сейчас автоматически выбираются только уже проверенные точные фразы, остальное можно приложить TXT вручную.
3. Импортировать `<Book>_New_Stress_Delta.txt` как новый именованный список во вкладке RuVoice → «Ударения»; при наличии правил импортировать `<Book>_Replacements.txt` отдельно во вкладке «Замены». `MyBooks_Cumulative.txt` — backup, не замена старым спискам.
4. На реальном телефоне открыть ту же EPUB в RuVoice и проверить полноту/порядок текста, ударения и одновременную озвучку.
5. Повторить реальный пользовательский цикл на второй EPUB; автоматический тест A/B/B-repeat уже есть.

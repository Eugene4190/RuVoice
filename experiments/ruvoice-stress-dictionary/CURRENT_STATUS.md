# Текущий статус личного workflow RuVoice

Дата: 2026-11-25. Ветка: `stress-dictionary-pipeline`. HEAD: `a7769ae540ee6c2c3fb26ff981e43089d280205a`.

## Уже реализовано

- Локальная страница загрузки `private_book_server.py`: доступ только через `127.0.0.1`, EPUB до 256 МБ и необязательный TXT с replacements. Есть token/Origin/Host checks; HTTP-логи не сохраняют названия и текст книг.
- Входные EPUB и replacement-TXT записываются в локальную временную папку с приватными правами. Оба временных файла удаляются до отправки браузеру ссылки на ZIP.
- Запуск: Windows — двойной щелчок по `Start_RuVoice_Book_Tool_Windows.bat`; macOS/Linux — `bash start_ruvoice_book_tool.sh`. Требуется Python 3.11+. Страница открывается на `http://127.0.0.1:8765/`.
- Личный append-only мастер находится вне Git: по умолчанию `~/.ruvoice-book-workflow` (Windows: `%USERPROFILE%\\.ruvoice-book-workflow`). Каталоги 0700 и файлы 0600 на POSIX. Это локальное хранение, не облако и не шифрование.
- `personal_book_workflow.py` автоматически добавляет в мастер только кандидатов разрешённых источников после проверки точной словоформы, е/ё, контекстных правил и конфликтов с мастером. Перед записью используется staged-копия и конфликтный валидатор; старое утверждённое ударение не перезаписывается.
- SHA-256 книги обеспечивает идемпотентность мастера. При повторе слово не добавляется повторно. Если ZIP нужно восстановить, исходная дельта книги повторно включается в пакет; инструкция предупреждает не импортировать её второй раз, если список уже есть в RuVoice.
- Приватная история хранит книгу первого добавления слова, источник, частоту и все книги, где слово встретилось позднее. Текст EPUB в историю и ZIP не включается.
- EPUB разбирается в порядке чтения из `META-INF/container.xml` и OPF `spine`; для минимальных/некорректных EPUB без этой структуры используется стабильный fallback.
- ZIP содержит `<Book>_New_Stress_Delta.txt`, `<Book>_Replacements.txt`, `MyBooks_Cumulative.txt`, `MyBooks_History.json`, `IMPORT.txt`, `Book_Report.json`, таблицы конфликтов, неизвестных форм и правил замен.
- Книжные replacements хранятся отдельно по SHA-256 книги. Пользовательский TXT можно приложить при загрузке; уже сохранённые правила сохраняются при повторной обработке.
- Есть первый ограниченный автоматический выбор контекстных замен: curated phrase rules попадают в ZIP только при буквальном совпадении в книге. Сейчас набор небольшой (проверенное правило «шелка и»); универсального извлечения новых фразовых замен ещё нет.

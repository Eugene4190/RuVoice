# Текущий статус личного workflow RuVoice

Дата контрольной точки: 2026-11-25.
Рабочая ветка: `stress-dictionary-pipeline`.

## Цель

Личный повторяемый сценарий: загрузить EPUB в приватную точку → получить ZIP с дополнением для этой книги → импортировать дельту в RuVoice → читать книгу с одновременной озвучкой. Личный словарь должен накапливаться между книгами, не терять старые записи и не плодить дубликаты.

## Что уже работает

- `build_book_dictionary.py` локально разбирает EPUB и создаёт результаты для конкретной книги: предварительные кандидаты, таблицы проверки/конфликтов, неразрешённые формы, отчёт и экспорт уже существующего накопительного списка.
- `analyze_book.py` анализирует покрытие и частоты словоформ.
- `approve_book_entries.py` поддерживает ручное append-only добавление только явно выбранных и утверждённых записей. Перед записью проверяет конфликты; конфликт не должен молча перезаписывать старую запись.
- Книжный сборщик читает `Системный.txt` и `RuVoice_Accumulated_Approved.txt` только для чтения. Он не записывает новые записи в мастер автоматически.
- `Book_Approved_Additions.txt` содержит ранее утверждённые записи мастера, которые встретились в текущей книге; это не автоматическая дельта новых утверждений.
- Результаты сборщика сейчас создаются в локальном каталоге `output/books/...`, а не в готовом пользовательском ZIP.

## Что не реализовано

- Приватная точка загрузки произвольной пользовательской EPUB-книги и серверный процесс обработки.
- Приватное постоянное хранилище личного накопительного словаря с автоматическим пополнением после каждой книги.
- Автоматическое утверждение безопасных новых записей и сохранение их в мастер-словарь. Нынешний `approve_book_entries.py` — ручной CLI-инструмент.
- ZIP, содержащий дельту текущей книги, полный накопительный snapshot, книжные контекстные замены при необходимости, инструкцию импорта и отчёт.
- Регрессионная проверка A → B → повтор B: A сохраняется, B добавляет только новое, повтор B не создаёт дублей, конфликт B не перезаписывает запись A.
- Реальная проверка на устройстве: импорт дельты в RuVoice, открытие той же книги, чтение и одновременное прослушивание.

## Важное состояние накопителя

`data/approved/RuVoice_Accumulated_Approved.txt` сейчас содержит только четыре строки-комментария и ноль утверждённых словарных записей. Следовательно, автоматическое накопление между книгами пока не работает, несмотря на наличие ручного append-only инструмента.

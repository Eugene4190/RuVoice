# Текущий статус личного workflow RuVoice

Дата: 2026-11-25. Рабочая ветка: `stress-dictionary-pipeline`.

## Что уже реализовано

- Локальная страница загрузки книг: `private_book_server.py`. Она слушает только `127.0.0.1`, принимает EPUB до 256 МБ (также TXT/HTML), не пишет имя книги или содержимое в HTTP-логи и после сборки удаляет временную загрузку.
- Запуск без ручного ввода команд: Windows — двойной щелчок по `Start_RuVoice_Book_Tool_Windows.bat`; macOS/Linux — `bash start_ruvoice_book_tool.sh`. Требуется установленный Python 3.11+. Страница открывается на `http://127.0.0.1:8765/`.
- Приватный накопитель вне Git-репозитория: по умолчанию `~/.ruvoice-book-workflow` (Windows: `%USERPROFILE%\\.ruvoice-book-workflow`); можно выбрать другой путь через `RUVOICE_PRIVATE_HOME` или `--private-home`. На POSIX применяются права каталогов 0700 и файлов 0600; это локальное хранение, не шифрование.
- `personal_book_workflow.py` запускает сборщик, дописывает в append-only мастер только записи из разрешённых источников, прошедшие точные проверки поверхности/е-ё, контекстных правил и конфликтов; использует существующий конфликтный валидатор перед заменой staged-копии мастера.
- Идемпотентность по SHA-256 книги: повтор той же EPUB не добавляет строк повторно, возвращает пустую дельту и сохраняет уже накопленные записи.
- Конфликтующее новое предложение для уже утверждённой точной формы выводится как `ACCUMULATED_MASTER_CONFLICT`; старое ударение не перезаписывается.
- История в приватном JSON хранит SHA-256, имя книги, дату, новые словоформы, источник и частоту. Сам текст книги в историю и ZIP не записывается.
- Книжные TXT-замены хранятся отдельно по SHA-256 книги и повторно попадают в ZIP при следующей обработке той же книги. Их можно приложить на странице загрузки как необязательный TXT-файл.
- Готовый ZIP содержит `Book_New_Stress_Delta.txt`, `MyBooks_Cumulative.txt`, `MyBooks_History.json`, `Book_Replacements.txt`, `IMPORT.txt`, `Book_Report.json`, таблицу конфликтов и unresolved-форм.

## Как пользоваться локальной страницей

1. Запустить `Start_RuVoice_Book_Tool_Windows.bat` или `bash start_ruvoice_book_tool.sh`.
2. Открыть `http://127.0.0.1:8765/`, выбрать EPUB и нажать «Собрать ZIP». Для книги можно дополнительно приложить TXT с её правилами во вкладку «Замены».
3. Скачать ZIP по ссылке на странице.
4. В RuVoice импортировать `Book_New_Stress_Delta.txt` как новый отдельный список во вкладке «Ударения». Не удалять и не выключать списки прошлых книг.
5. Если в `Book_Replacements.txt` есть правила, импортировать его отдельно во вкладку «Замены». `MyBooks_Cumulative.txt` — резервная копия, не файл для замены всех списков приложения.
6. Открыть книгу в RuVoice и проверить чтение/озвучку.

Файлы хранятся на этом компьютере. Для использования на телефоне перенеси ZIP на устройство вручную; localhost-страница не является интернет-сервисом и не синхронизируется с телефоном.

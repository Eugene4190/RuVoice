# Независимая контрольная выборка ударений (gold set)

## Назначение

Каталог `data/gold` содержит проверяемые вручную нормативные примеры. Он нужен, чтобы оценивать отдельные формы ударения и контекстные решения на эталоне, не зависящем от предсказаний RuVoice, RUAccent или голосования AOT/Wiktionary.

Начальный набор `seed.tsv` намеренно мал (10 употреблений с проверенными ссылками на источники). Это **стартовая разметка для проверки инструментария**, а не репрезентативная выборка русского языка и не основание заявлять процент качества всего словаря. Записи проверены по указанным источникам в рамках этой работы, но ещё не прошли независимую вторую лингвистическую разметку.

## Принципы разметки

- Одна строка — одно конкретное употребление словоформы в заданной грамматике, значении и контексте.
- Для омографичного написания с разными ударениями создаются отдельные строки с разными `sense_id` и контекстами.
- `accepted_marked` перечисляет все варианты, подтверждённые источником. Нормативные варианты не считаются ошибкой друг друга.
- `primary_marked` заполняется только когда источник позволяет выделить рекомендуемый вариант. При равноправной вариантности поле остаётся пустым.
- `evaluation_scope=word` — случай можно оценить по словоформе без смыслового разбора. `contextual` — нужен контекст/значение; нельзя трактовать такую строку как обычную запись глобального словаря без контекстного разрешения.
- `source_url` и краткое содержание основания обязательны. Проверка источника датируется в `reviewed_on`.
- Сомнительные случаи не следует включать до появления надёжного независимого основания. При появлении разных редакций нормы хранить их отдельно и явно указывать дату/статус.
- Если источник приводит несколько вариантов, evaluator засчитывает любой вариант из `accepted_marked`; он не требует угадывать единственный «primary».

## Формат TSV

`gold_id, surface, lemma, part_of_speech, morph_features, sense_id, context, primary_marked, accepted_marked, evaluation_scope, category, source_title, source_url, evidence, reviewed_on`.

Ударение записывается знаком `+` непосредственно перед ударной гласной. Список допустимых вариантов разделяется символом `|`. Написание `surface` сохраняется точно: е и ё не сливаются при идентификации gold-записи.

## Начальные примеры

- `творог`: оба нормативных варианта, поэтому нет единственного primary.
- `создана`: рекомендуемое и допустимое ударение хранятся раздельно.
- `средам` и `средами`: разные грамматические формы/значения, ударение зависит от значения и контекста.
- `позвонит`: конкретная форма будущего времени, а не абстрактное правило по лемме.
- `маркированный`: одинаковое написание в лингвистическом и обычном значении размечено двумя контекстными строками.
- `обеспечение`: принимаются две словарно зафиксированные позиции ударения.
- `ходатайство` и `щавель`: добавлены как контрольные формы, включая отрицательный пример для распространённого ненормативного ударения.

## Оценка

Скрипт `evaluate_gold_set.py` проверяет TSV и по желанию принимает файл предсказаний с колонками:

```tsv
gold_id    predicted_marked
G001       твор+ог
G002       создан+а
```

Пустое поле или `ABSTAIN` означает отказ от предсказания. В отчёте раздельно считаются:

- coverage — доля строк gold set, для которых сделано предсказание;
- exact accuracy among emitted — доля правильных среди сделанных предсказаний (варианты из accepted считаются правильными);
- preferred variant match rate — совпадение с рекомендованным вариантом среди строк, где он явно задан; допустимый альтернативный вариант остаётся нормативно правильным и отдельно учитывается как accepted non-primary prediction;
- accuracy over all gold rows — доля правильных от полного набора, где пропуски/abstentions не дают правильного ответа;
- разбивка по evaluation scope и category.

Для контекстных строк следует использовать контекстно-чувствительный предсказатель/разметчик. Простая словарная запись с одним ударением не может одновременно выразить два смысла слова `маркированный`.

Перед расширением набора нужно ревьюить не только написание и ударение, но и часть речи, грамматическую форму, значение, контекст, допустимость вариантов и точную цитату/ссылку на лексикографический источник. Перед использованием показателей как внешнего quality claim весь набор должен пройти независимую вторую лингвистическую разметку и разрешение разногласий.


## Очередь кандидатов для независимой второй разметки

Файл `review_queue.tsv` хранит source-backed предложения для будущего расширения. Это **не gold set**: ни одна строка из очереди не входит в `seed.tsv`, не проверяется evaluator как эталон и не может использоваться в метриках точности до завершения независимой второй лингвистической разметки и разрешения разногласий.

Каждая строка содержит точную словоформу, грамматические признаки, естественный контекст, варианты ударения, источник и поля для второго рецензента. Статус `AWAITING_SECOND_LINGUIST_REVIEW` означает, что выполнен только первый проход по указанному источнику. После второй проверки следует записать решение, дату, разногласия и основание; только затем переносить согласованные строки в `seed.tsv` с постоянным `gold_id`.

Очередь теперь также содержит точные различия е/ё для «берег» (существительное) и «берёг» (форма глагола «беречь»), а также две отдельные контекстные записи с одинаковым написанием «пахта»: па́хта (молочный продукт) и пахта́ (хлопок). Это разные лексемы/значения, а не допустимые варианты одного слова. Все записи остаются в статусе ожидания второй разметки. Очередь пока не покрывает все запланированные классы.

# Exported dictionaries

TXT files in this folder use the official RuVoice user stress dictionary format:
one line per entry, as: word stressed+word

- RuVoice_Stage4.9_ExistingFixes.txt is a snapshot of the checked-in Stage 4.9 fix list. It may duplicate entries already present in an APK built from Stage 4.9.
- RuVoice_AutoStress.txt is reserved for the full automated AOT + Wiktionary run.

Do not commit source dumps or temporary corpora here.

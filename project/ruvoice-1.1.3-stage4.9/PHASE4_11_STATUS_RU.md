# Этап 4.11 — первый APK RuVoice Improved

## Что подтверждено

- Реальный RUAccent INT8 загружен из закреплённой ревизии Hugging Face: 16 файлов, 144 301 606 байт.
- Все четыре ONNX-сессии созданы, warm-up и четыре русских smoke-примера пройдены в JVM на Linux.
- Для всех 16 файлов закреплены SHA-256; установщик сверяет каждый файл до пометки «установлено».
- Настоящий HTTP Range downloader прошёл локальные сценарии прерывания/возобновления, игнорирования Range, неверного Content-Range и HTTP 416.
- Официальный пакет ru_voices проверен: speaker `ilya` присутствует под id 20.
- Минимальная версия Android для этой модификации: API 24 (Android 7.0), требование ONNX Runtime 1.32.0; целевой Xiaomi работает на Android 13.
- Экспериментальному APK назначен отдельный applicationId `ru.kost.ruvoice.improved`: он устанавливается рядом с официальным RuVoice и не заменяет его данные.
- Сохранены оригинальные Silero v5_5_ru assets из официального RuVoice 1.1.3. Голос Ilya доступен через официальный пакет ru_voices.

## Сборка

- Variant: `fullDebug`, ARM64.
- Unit tests: `:app:testFullDebugUnitTest`.
- APK: `ruvoice-improved-1.1.3.apk`.
- APK bytes: 290065834.
- APK SHA-256: `b55e9aece1c51db26cf86d416bc08dbe45f1014f2587f636a744bd8d079b6fc5`.

## Установка и первый запуск

1. Установить APK рядом с официальным RuVoice.
2. В RuVoice Improved открыть «Голос» и установить пакет голосов `ruvoice-pack-ru_voices.zip` через «Дополнительные голоса».
3. Выбрать `ilya`.
4. В разделе голоса нажать «Загрузить офлайн-модель RUAccent». Загрузка около 144 МБ, поддерживает возобновление.
5. После успешной активации обработка выполняется локально и не отправляет текст книги в сеть.

## Не подтверждено

- Физический запуск и производительность на Xiaomi Redmi Note 12 Pro 4G / Snapdragon 732G.
- Расход RAM, температура и задержка синтеза на телефоне.
- Точность относительно эталонной разметки: в загруженной EPUB-книге нет gold-разметки ударений; парное сравнение показывает различия конвейеров, но не доказывает, что каждое изменение исправляет ошибку.
- Подпись ключом разработчика официального приложения (используется debug signing, отдельный package id).

Это экспериментальная сборка для установки рядом с оригиналом, а не официальный релиз RuVoice.

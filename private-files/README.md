# Личные файлы

Эта папка предназначена для файлов, которые добавляет владелец репозитория **@Eugene4190**.

## Как загрузить файл

1. Откройте папку `private-files` в GitHub.
2. Нажмите **Add file → Upload files**.
3. Перетащите файлы или выберите их на устройстве.
4. Нажмите **Commit changes**.

## Доступ и конфиденциальность

- Репозиторий `Eugene4190/RuVoice` должен оставаться **Private**.
- GitHub не поддерживает отдельные права доступа на уровне папок: разрешение на запись действует на весь репозиторий.
- Поэтому добавлять файлы сюда сможет любой пользователь, которому выданы права записи в репозиторий. Чтобы загружать файлы могли только вы, не выдавайте другим пользователям права Write, Maintain или Admin.
- Участники с правом только Read смогут просматривать файлы, но не загружать и не изменять их.
- Не храните здесь пароли, токены, приватные ключи и другие секреты: приватный репозиторий не является зашифрованным хранилищем.

Эта папка — обычное хранилище файлов внутри приватного репозитория; она не меняет код и сборку RuVoice.

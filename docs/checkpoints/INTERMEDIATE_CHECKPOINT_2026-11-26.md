## Что ещё не готово — блокеры до выдачи пользователю

1. Полный desktop runtime ещё не собран и не включён в действующий Windows packaging workflow. В репозитории лежит экспериментальный снимок Gradle-конфигурации, но задача сборки desktop runtime не встроена и не проверена. Не подтверждены сборка и комплектность:
   - JRE;
   - production Kotlin/JVM классы и их зависимости;
   - официальные Silero-модели;
   - native tokenizer/JNI DLL;
   - оба режима portable model worker;
   - локальные AOT-данные и остальные ресурсы.
2. PyInstaller worker и весь локальный оркестратор не прошли сквозной Windows smoke test на полном оригинальном RuVoice. Нынешний workflow сборки Windows по-прежнему содержит старую ограниченную схему; её успешная synthetic upload-проверка не означает готовности full-book инструмента.
3. Не выполнен повторный полный paired-run на контрольном EPUB после исправления прежней Kotlin compile error.
4. Не проведён performance benchmark на книге примерно в 65 тысяч словоупотреблений. Нельзя достоверно обещать длительность в минутах, пока не будет замера на целевой Windows-машине.
5. Новая фильтрация третьей модели проверена unit-тестами, но не сравнена на полной книге с прежним exhaustive third-model audit. Перед выпуском необходимо сравнить множества кандидатов/исключений и убедиться, что выбранная стратегия не теряет классы исправлений, которые действительно должны импортироваться.
